# Contributing

Thank you for your interest in contributing.

## Development Workflow

1. Create a feature branch.
2. Make focused changes.
3. Run formatting tools.
4. Run tests.
5. Submit a Pull Request.

---

## Formatting

```bash
uv run black .
```

---

## Linting

```bash
uv run ruff check .
```

---

## Running Tests

```bash
uv run pytest
```
